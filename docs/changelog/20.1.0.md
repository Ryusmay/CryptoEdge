# CryptoEdge 20.1.0

- Nowy terminalowy shell z sześcioma samodzielnymi widokami: DESK, SCAN, LAB, REPLAY, HISTORY i SET.
- Nowa hierarchia DESK: rynek i sesja, następnie kandydaci/pozycje/ryzyko, na końcu zdarzenia.
- Globalny pasek pokazuje wersję, tryb, stan analizy i handlu, połączenie BloFin, reżim oraz kapitał.
- LAB, REPLAY, HISTORY i SET nie są już bezpośrednio podpinane jako stare strony.
- Naprawiono błąd arkusza QSS, przez który style kart, formularzy i kontrolek były ignorowane.
- Zaktualizowano regresje architektury UI do nowego kontraktu stron terminalowych.

Logika strategii, ryzyka, replay i egzekucji nie została zmieniona w tym wydaniu.
