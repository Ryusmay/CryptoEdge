# CryptoEdge 19.32.0

- Główne sterowanie uproszczone do `START BOT` i `STOP BOT`.
- `START BOT` uruchamia analizę oraz handel i nie działa już jak przełącznik.
- `STOP BOT` zatrzymuje jednocześnie analizę oraz handel.
- Usunięto z głównego UI osobne `STOP TRADING`, `PAUSE` i `RESUME`.
- `CLOSE ALL` pozostaje oddzielną awaryjną funkcją zarządzania pozycjami.
