# CryptoEdge v20.12.1

## Powrót do natywnego Tauri

- Przywrócono jedno deklaratywne okno Tauri `main` zamiast pustej listy okien
  i programowego tworzenia WebView.
- Usunięto niestabilne wymuszanie widoczności okna z dodatkowego wątku oraz
  niestandardowy katalog danych WebView2.
- Launcher nie uruchamia już Microsoft Edge. Otwiera natywne
  `CryptoEdge_Terminal.exe`.
- Backend startuje w tle tylko wtedy, gdy API CryptoEdge nie jest dostępne.
- Zamknięcie UI zatrzymuje wyłącznie backend utworzony przez dany launcher;
  wcześniej działający silnik pozostaje nietknięty.
- PySide6 pozostaje awaryjnym, niezależnym trybem uruchomienia.
