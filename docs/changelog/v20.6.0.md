# CryptoEdge v20.6.0

## Strategy quality and calibrated expectancy

- DAYTRADING_V2 now uses the probability-weighted daytrading expectancy model.
- PAPER outcomes from DAYTRADING_V2 update TP1/TP2 calibration.
- Calibration is segmented by major/alt profile and market regime.
- TP1 is capped before a confirmed 1h obstacle when executable reward remains.
- Target clearance reduces P(TP) instead of creating an arbitrary hard gate.
- Added causal candle-rejection features: wick, close location, body, ATR range,
  relative volume and zone-touch age.
- Added confirmed-pivot RSI divergence, RSI slope and conservative failure swing.
- New technical features start as telemetry and bounded probability modifiers;
  they are not standalone entry signals.
- Decision telemetry records target-path, candle and RSI feature attribution.
- Fibonacci remains confluence and target mapping, never a standalone signal.

## Validation policy

Promoting any new feature to a hard gate requires OOS/PAPER marginal contribution,
cost stress and parameter-neighbour stability.
