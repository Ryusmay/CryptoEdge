# CryptoEdge v17.15 — External BloFin Positions

- Ręczne pozycje BloFin są odróżniane od pozycji zarządzanych przez CryptoEdge.
- Zewnętrzne pozycje nie blokują powrotu z podglądu LIVE do DEMO.
- Przed zmianą użytkownik otrzymuje listę pozycji i potwierdza pozostawienie ich bez zmian.
- CryptoEdge nie zamyka ani nie modyfikuje ręcznych pozycji podczas zmiany trybu.
- Pozycje otwarte i zarządzane przez aktywną egzekucję bota nadal blokują opuszczenie LIVE.
