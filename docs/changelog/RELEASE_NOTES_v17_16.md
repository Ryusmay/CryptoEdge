# CryptoEdge v17.16 — Daytrading Readiness Score

- Monety w trybie Daytrading otrzymują widoczny score także podczas oczekiwania.
- Score składa się z jakości danych, zgodności 4H/1H, CHOP/ADX na 15m, setupu 15m i timingu 5m.
- Neutralny readiness score nie może samodzielnie uruchomić transakcji.
- Pełne wejście nadal wymaga kierunku LONG/SHORT i wszystkich dotychczasowych bramek.
- Analysis Workspace otrzymuje komponenty score oraz dokładny powód oczekiwania.
