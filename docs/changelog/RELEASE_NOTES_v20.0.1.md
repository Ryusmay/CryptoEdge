# CryptoEdge v20.0.1

- Uproszczono komunikaty OPEN/CLOSE w zakładce Events.
- OPEN pokazuje symbol i cenę otwarcia.
- CLOSE pokazuje symbol, cenę zamknięcia oraz zysk albo stratę w USD.
- Szczegółowe przyczyny, wielkość, kierunek i kapitał nadal są zapisywane w
  logach audytowych, ale nie zaśmiecają widoku operatorskiego.
