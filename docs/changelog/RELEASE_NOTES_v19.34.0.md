# CryptoEdge 19.34.0

- Zakładka Events nie pokazuje technicznych wpisów `CYCLE`.
- Podczas startu pokazuje jeden status: `Rozgrzewanie silnika · X z Y monet dostępnych do analizy`.
- Po pełnym rozgrzaniu pokazuje: `Silnik rozgrzany · Y monet dostępnych do analizy`.
- Gotowość oznacza przejście całego uniwersum przez cold-start V2, a nie tylko minimalną bramkę bootstrapu.
- Cykle nadal są zapisywane w logach audytowych i telemetrii.
