- Dodano centralny stream market data: osobny loopback WebSocket 47822, snapshot/delta/heartbeat, `session_id`, `sequence_id`, stale detection, resync REST, limity originu/klientów/ramki i bounded reconnect.
- Podłączono read-only modele historii, equity/drawdown, ekspozycji, reconciliation i telemetrii sygnałów do workspace’ów.
- Dodano wirtualizowaną historię transakcji oraz wykres z rzeczywistymi poziomami ENTRY/SL/TP i markerami fill/exit; niepełne dane są pomijane bez zgadywania.

- Tauri 2 otrzymał single-instance, tray i bezpieczny lifecycle. Nie zgaduje ścieżki Pythona i nie zatrzymuje procesu, którego sam nie uruchomił.
- Ujednolicono backend, React, npm, Cargo i Tauri na 20.37.0; usunięto nieużywaną kopię `frontend/engine_api.py`.
- Zastąpiono browser `confirm()` aplikacyjnym dialogiem, dodano reveal dla sekretów, `noValidate`, tytuły widoków i usunięto fałszywe kontrolki interwału.
- Dodano `DESIGN.md`, `UX-CONTRACT.md`, rygorystyczny audyt UI oraz testy regresyjne transportu i projekcji.
